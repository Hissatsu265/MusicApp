# Flutter Music App

A modern and feature-rich music player application built with Flutter and Dart.

## Features

- Intuitive and beautiful user interface inspired by Material Design 3
- Local music playback with support for multiple audio formats
- Create and manage playlists
- Advanced audio controls (shuffle, repeat, queue management)
- Background playback support
- Dynamic theme support (Light/Dark mode)
- Audio visualization
- Lyrics display support
- Search and filter functionality

## Getting Started

### Prerequisites

- Flutter SDK (version 3.0 or higher)
- Dart SDK (version 3.0 or higher)
- Android Studio / VS Code
- Android SDK for Android deployment
- Xcode for iOS deployment

### Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/flutter-music-app.git
```

2. Navigate to the project directory:
```bash
cd flutter-music-app
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```
